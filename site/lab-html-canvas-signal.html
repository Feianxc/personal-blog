可阅读 HTML + 高能 Canvas 背景 / WebGL 优先

高能视觉层可以进入 Canvas，但正文必须留在可阅读的 HTML 里。

这个页面用 PixiJS 画画布层、粒子和 Canvas 内标签，用 GSAP 控制状态切换。它只测试视觉层，不把博客正文、导航和链接画进 Canvas。

PixiJS 8.18.1 GSAP 3.15.0 WebGL 默认 / WebGPU 手动探针

实验控制

渲染器 检测中…

默认不启用 WebGPU。只有 URL 带 ?webgpu=1 且浏览器支持时，才会尝试 WebGPU；失败会回退。

这个实验先放在独立页面

独立 lab 页只保存 PixiJS、GSAP、模式切换、降级和测试记录；首页默认首屏仍保持轻量。

Canvas 只负责气氛，正文仍是普通网页

保留 HTML 标题、段落、链接、导航都还是 DOM

这样 SEO、复制、阅读器、键盘访问和后续写文章不会被牺牲。

Canvas 专职 背景、粒子、记录线和高能模式交给 Pixi

把“好看但不该挡内容”的部分放进一个可卸载的视觉层。

GSAP 只管节奏 状态切换、爆发、回落，不接管全站滚动

这和现有“安静 / 风暴 / 高能”的控制台逻辑可以自然合并。

高能模式按需加载，默认首页保持轻量

它不替换首页雨幕，也不默认加载；轻量雨幕保留为默认态，PixiJS / GSAP 版本只在高能模式下懒加载。 

点击“高能”
  → 按需加载 PixiJS + GSAP
  → 挂载 Canvas 视觉层
  → 安静模式 / 减少动态效果 / 页面隐藏时停止并清理

这页的结论不是“以后整站都用 Canvas”，而是视觉层可以继续往前试，但正文仍然要有真实 HTML 骨架。
