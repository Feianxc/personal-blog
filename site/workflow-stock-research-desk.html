老板研究台 V1：压缩股票池，但不越过人的判断

dailyQueue、focusBriefs 和 styleMemorySummary 负责压出今天该看的票。

这个项目不碰自动交易。它像一张研究桌面：后台把股票池压缩成今天值得看的几项，前台把材料递上来；通过、退回和备注再回流成风格记忆。

不是不是自动交易 / 自动下单 / 券商直连

不碰自动下单

自动化选股很容易写过头：全市场扫描、AI 判断、自动执行。但当前仓库把范围写得比较清楚：它是研究压缩 + 风格学习工作台，不是交易执行系统。这个“不做”是项目范围。

研究台靠哪些对象撑住

对象现在放在哪为什么不能少
产品前台product/index.html / styles.css / app.js老板打开的是桌面，不是后端日志；三大视图要在前台收住。

交接文档docs/PROJECT_HANDOFF.md / BOSS_MIRROR_V1.md它们把当前定位从“系统很完整”改成“帮助老板更快处理今天研究任务”。

从股票池到老板桌面

agentUniversechunkSize = 10push / watch / dropagentDeskdailyQueueAI 团队晨会
1. 股票池先进入 agentUniverse
2. 按 chunkSize = 10 切成分队批次
3. 分队先分层：push / watch / drop
4. 主研究台汇总成 agentDesk
5. 面向老板再压成 dailyQueue / focusBriefs / styleMemorySummary
6. 需要进一步收敛时，再触发 AI 团队晨会：侦察 / 分析 / 风险 / 简报

这套流程不替老板拍板，只减少当天不值得立刻看的噪音。
