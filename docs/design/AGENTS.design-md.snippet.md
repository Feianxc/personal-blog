# DESIGN.md project rule snippet

When working on this project's visual/frontend surfaces:

1. Read `docs/design/DESIGN.cursor.md` before changing layout, colors, typography, navigation, buttons, cards, or hero sections.
2. Treat `Cursor` / `cursor` as visual grammar only. Do not copy logos, brand names, exact layouts, proprietary fonts, screenshots, or distinctive trade dress.
3. For Chinese UI, adapt font fallbacks, line-height, copy length, mobile wrapping, and visible control labels.
4. After implementation, update or complete `docs/design/frontend-scorecard.md` with concrete browser/static evidence.
5. If the page is public or client-facing, describe the result with neutral style language rather than "clone/fake/copy <brand>".
